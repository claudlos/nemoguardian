The cascade

Cheap → expensive. Streaming → full-doc → custom policy → optional deep triage. You choose when to pay for the heavier reasoning path.

fast

Streaming guard

Qwen/Qwen3Guard-Stream-0.6B
  • ~1 ms / token
  • Token-level streaming moderation
  • Catches obvious violations as the LLM types

Full-doc guard

Qwen/Qwen3Guard-Gen-4B
  • ~50 ms per message
  • 119 languages, 3-tier (safe / controversial / unsafe)
  • Nuanced violations, multilingual
standard

Custom-policy reasoning

nvidia/Nemotron-Content-Safety-Reasoning-4B
  • ~200 ms per message
  • Reasoning-on, enforces your YAML policy
  • Topic-following, jailbreak detection
deep

Deep triage

nvidia/nemotron-3-ultra-550b-a55b (API-only)
  • ~300 ms per batch
  • Adjudicates disagreements
  • Explains the verdict in plain English

Modes

Callers pick a mode per request. Pay only for the reasoning you need.

fast

Token-level streaming moderation. Sub-millisecond per token. For LLM output filtering, live chat token streams, anywhere you'd reach for a regex but want better recall.

POST /v1/moderate/stream

standard default

Full-document cascade: Qwen3Guard-Gen + Nemotron-CSR. Covers 119 languages with custom YAML policy enforcement. This is the workhorse.

POST /v1/moderate

deep

Standard + API-backed Nemotron 3 Ultra triage. Use it when the local guards disagree, when the customer needs a richer explanation, or for audit reports.

POST /v1/moderate?mode=deep

Quickstart

Up and running in three commands. First moderation call downloads model weights.

Local

$ python3 -m venv .venv && . .venv/bin/activate
$ pip install -e ".[dev]"
$ NEMOGUARDIAN_ENABLE_DEMO_ENDPOINT=1 \
    python -m nemoguardian serve --port 8000

# open http://localhost:8000/demo

Self-hosted (GPU)

$ cp .env.example .env       # set NEMOGUARDIAN_API_KEY
$ docker compose up --build

$ docker compose exec nemoguardian \
    python scripts/real_model_smoke.py

$ curl -X POST http://localhost:8000/v1/moderate \
    -H "Authorization: Bearer $NEMOG...EY" \
    -H "Content-Type: application/json" \
    -d '{"text":"hello world","mode":"standard"}'

The /demo/moderate endpoint is disabled by default — opt in only for controlled demo hosts. Production calls go through POST /v1/moderate with a real nmg_... API key.

Security posture

This project has had two internal security passes (NMG-001 → NMG-013). Everything is fixed — webhook signature verification and replay idempotency, non-root container, CORS allowlist, SSH-key validation, sanitized errors, per-key rate limiting, scoped instance tokens, pinned model revisions — except one: adversarial robustness of the guard models themselves (NMG-006), which has a prepared eval harness in eval/ awaiting a GPU run.

Production deployments should run behind an authenticated reverse proxy, set NEMOGUARDIAN_ENABLE_DEMO_ENDPOINT=0, supply a non-placeholder NEMOGUARDIAN_API_KEY, and review SECURITY.md before exposing the service to the internet.
